# Каргономика — лендинг поверх интерактивной Земли

Полный прототип главной страницы: весь контент из Фигмы («Прототип — Земля в хиро») поверх интерактивной Земли.
Работают калькуляторы, карусели, форма, ховеры и анимации блоков.

Интерактив в соседней папке `../web` не изменялся. Здесь лежит его копия (`src/earth`).

## Как открыть

- **`standalone/cargo-landing.html`** — один файл, открывается двойным кликом. Шрифты, картинки и код уже внутри, интернет не нужен.
- Разработка:

```bash
npm install
npm run dev       # локальный сервер Vite
npm run build     # dist/ для хостинга
npm run package   # пересобрать standalone/cargo-landing.html
```

Параметры в адресной строке те же, что у интерактива: `?debug` открывает панель настройки Земли, `?p=0.5` фиксирует кадр.

## Как устроено

```

src/data/economics.js    цифры калькуляторов (заглушки, см. ниже)
src/ui/
  header.js              шапка: стекло, прячется при скролле вниз; меню «Экосистема»; мобильное меню
  hero-strip.js          первый экран: плашка внизу показывает сцепку, на которую навели
  reveal.js              появление блоков, счётчики, параллакс, цитата по словам, вход в хиро
  units.js               блок 03 «Сумма эффективности при выбранных юнитах»
  fleet.js               блок 07 «Посчитайте эффективность своего парка»
  carousel.js            карусели 04 и 10: перетаскивание с инерцией, стрелки, свайп тачпадом
  form.js                форма: маска телефона, проверка, загрузка, экран «Заявка отправлена»
  pointer.js             подсветка под курсором, «магнитные» кнопки, наклон карточек принципов
  anchors.js             плавные переходы по якорям и связи между блоками
src/styles/              стили и локальные шрифты
public/img/              оригиналы картинок из Фигмы (оверлеи из макета уже наложены)
tools/package.mjs        сборка standalone-файла
```

### Земля

- `canvas#globe` закреплён под всей страницей (`position: fixed`), контент идёт поверх (`z-index: 1`).
- Прогресс Земли: `p = scrollY / (footer.offsetTop − innerHeight)`. При `p = 0` виден первый экран, при `p = 1` футер показывается снизу — это самая дальняя точка.
- `src/earth/earth.js` — это `web/src/main.js` с двумя отличиями: прогресс считается по всей странице до футера, а не по блоку `#scroll`, и в конце добавлен экспорт `lenis` / `gsap` для страницы. Остальные файлы `src/earth` побайтно совпадают с `web/src`.
- Внешний вид настраивается в `src/earth/config.js`, как и в интерактиве.
- Версия Земли — финальная, без муара (суперсэмплинг рельефа, LOD изолиний, сглаженные облака), сверена с `web/src` 01.10.2026 20:00. Если интерактив снова обновится, скопируйте файлы из `web/src` в `src/earth` (кроме `main.js` → он уже лежит здесь как `earth.js`).

### Первый экран

- Кнопка «Поднять эффективность моего парка» ведёт к калькулятору. На ховере белый круг со стрелкой заливает кнопку.
- Над плашкой статистики есть пометка: «Вся информация отображается в реальном времени на основании данных системы Карго Мониторинг». Ссылка «Карго Мониторинг» ведёт к карточке сервиса.
- При наведении на сцепку (точку на Земле) нижняя плашка переключается на её данные, как в макете «Главный экран с информацией по наведению на конкретную сцепку»: номер, модель, загрузка, пробег в сутки, эффективность и маршрут «город | пройдено м» — «город | осталось м».
  - Пока плашка открыта, сцепка «едет»: слева метры растут, справа уменьшаются, полоса с бегунком ползёт вправо.
  - Скорость задаёт `CRAWL` в `src/ui/hero-strip.js`.
  - После ухода курсора плашка через 1,2 с возвращается к общей статистике.
  - Ниже первого экрана снова работает обычная карточка интерактива.
- Модель и маршрут сцепки подставляются автоматически. Модель берётся из списка, города — ближайшие узлы сети к западу и востоку от точки, метры считаются по расстоянию. Если API начнёт отдавать поля `model`, `from`, `to`, `traveled`, `remaining`, они будут использованы как есть.
- Наведение на точки работает везде, где курсор над Землёй, а не над карточкой. У секций стоит `pointer-events: none`, у «плотных» элементов (`.solid`, ссылки, кнопки, поля) — `auto`.

### Калькуляторы

Все цифры собраны в `src/data/economics.js`. Это **заглушки**: они подобраны так, чтобы стартовые состояния совпадали с макетом.
- В блоке 03 выбраны Топливо и Торговый дом: 96 000 ₽, стыков 1.
- В блоке 07 выбраны 25 тягачей и все 9 сервисов: 10 625 000 ₽, на тягач 425 000 ₽, на стыках 3 350 000 ₽, стыков 9 / 9.

Как считается:
- Выгода на сцепку равна сумме выбранных сервисов плюс бонусы стыков.
- Стык замыкается, когда выбраны оба соседа по кольцу экосистемы. Кольцо задано в `RING`, бонусы стыков — в `JUNCTION_VALUE`.
- В блоке 07 результат умножается на число тягачей. Шкала слайдера нелинейная, как в макете (25 ≈ 35 % трека).

Если заменить цифры реальными, разметка и анимации пересчитаются сами.

Обратите внимание, что в макете цифры между блоками не сходятся:
- Блок 06 обещает «> 235 тыс. ₽» за Топливо.
- Блок 03 обещает «до 1 млн ₽ на сцепке».

Модель повторяет стартовые состояния 03 и 07, а тексты 06 и сноска 03 оставлены как в макете.

### Форма

Реальной отправки нет. После проверки полей показывается экран «Заявка отправлена». Отправку на сервер нужно добавить в `src/ui/form.js`, в обработчик `submit`.

## Отличия от макета

- **Шрифт.** Используется Onest, открытая замена TT Hoves. TT Hoves стоит первым в `font-family`: если подключить его веб-файлы (`@font-face` с именем «TT Hoves»), он подхватится сам.
- **Белые и серые плашки** сделаны матовым стеклом: полупрозрачная заливка, размытие и насыщение фона, диагональный блик, лёгкое «зерно», светлая кромка и мягкая тень. Сквозь стекло видна Земля. Вторичный текст на стекле чуть темнее, чем в макете, чтобы держать контраст. Тёмные карточки с текстурами остались непрозрачными.
- **Карточки 4–6** в карусели «Экосистема» и **кейс «Союз-Регион»** в макете были в старом стиле (синие акценты, другой шрифт). Здесь они приведены к стилю соседних карточек. Тексты-заглушки («Сервис X…», «логотип») сохранены.
- **Кнопка первого экрана** теперь называется «Поднять эффективность моего парка» и сделана заново (см. «Первый экран»).
- **Логотип «Ультралогистики»** показан целиком. В макете он обрезан рамкой 150 px.
- **Слайдер парка** показывает текущее число тягачей над ползунком. В макете значения не было видно.
- **Меню «Экосистема»** раскрывается списком продуктов из футера. Остальные пункты меню и ссылки ведут к блокам этой страницы, потому что других страниц пока нет.
- **Новые элементы, которых нет в макете:**
  - анимации появления;
  - счётчики цифр;
  - параллакс;
  - раскрытие карточки «Как мы делаем…» при скролле;
  - подсветка карточек под курсором;
  - «магнитные» кнопки;
  - подсказка соседей-стыков при наведении на юнит;
  - всплывающая разница суммы в блоке 03;
  - связь «Как это работает →» с калькулятором (подставляет набор сервисов).
- **Адаптив.** Макет есть только для 1440, поэтому версии для планшета и телефона собраны по той же сетке.

## Производительность

CSS собирается минификатором esbuild (`cssMinify: 'esbuild'` в `vite.config.js`), потому что стандартный lightningcss выбрасывал `backdrop-filter` без префикса, и в Chrome пропадало размытие.

Земля рендерится постоянно. Сам интерактив снижает разрешение, если кадры не успевают. Стекло (`backdrop-filter`) на десятке карточек поверх WebGL нагружает видеокарту. Если на слабых машинах будет тяжело, увеличьте непрозрачность и уберите размытие в `--glass-*` и `--blur` в `src/styles/main.css`. При `prefers-reduced-motion` анимации блоков отключаются.
